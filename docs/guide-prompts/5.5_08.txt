Create an agent called challenger for the Phase 3 agent team in CLAUDE.md. It reads the register, auditor-comments.md, risk-ratings.json, analytics.json, history.json, rules.json and the planner's pack, and owns only outputs/challenges.md. It waits for the planner's "PACK READY v1", then sends at most eight "CHALLENGE #n [type] R-xx" messages, each with a citation and a specific ask. Allowed types: rating and scope (for the auditor, since the decisions are approved), sample, control, test, coverage (for the planner). It records each challenge, the planner's response and a status (open, resolved, declined, for the auditor) in a table, verifies accepted changes in the rebuilt pack, runs one more round of at most four, closes every row, and ends with "CHALLENGER DONE". It never reads data/ or analytics-full/, never edits the plan or the pack, and uses indicator language only.
